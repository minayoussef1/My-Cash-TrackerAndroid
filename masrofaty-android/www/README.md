# My Cash: Tracker 💰

تطبيق ويب خفيف لتتبّع المصروفات والدخل والديون والادخار، بيشتغل من غير إنترنت وبيتثبّت على الموبايل زي أي تطبيق (PWA). ملف واحد، من غير أي مكتبات خارجية، وكل بياناتك بتتحفظ على جهازك.

A lightweight, offline-first expense tracker (PWA). Single HTML file, no external libraries, all data stays on your device.

## المميزات / Features

- تسجيل المصروف والدخل والتحويل بين المحافظ (كاش، بنك، فيزا، محافظ إلكترونية)
- السلف والديون بالأشخاص
- ميزانية لكل بند + حد يومي للمصروف + قاعدة 50/30/20
- فواتير ثابتة وعمليات متكررة واشتراكات مع تنبيهات
- أهداف الادخار + توقع نهاية الشهر
- تقارير ومقارنة بين الشهور + تصدير PDF و CSV
- إيصالات بالصور + فلتر متقدم في العمليات
- ملفات متعددة للعائلة مع تقرير مجمّع
- نسخ احتياطي تلقائي أسبوعي + استرجاع
- عدة لغات، وضع فاتح/داكن، وأرقام عربي أو إنجليزي

## التشغيل / Run

افتح `index.html` في المتصفح مباشرة، أو انشره على **GitHub Pages**:

1. ارفع الملفات دي على مستودع GitHub جديد (في الجذر `/`).
2. من **Settings ← Pages** اختار **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقيقة هيبقى التطبيق على `https://USERNAME.github.io/REPO/`.
4. على الموبايل افتح الرابط واختار **إضافة إلى الشاشة الرئيسية**.

## ملحوظات

- البيانات محفوظة في `localStorage` على الجهاز، فاعمل نسخة احتياطية من **الإعدادات ← النسخ الاحتياطي** قبل ما تمسح بيانات المتصفح.
- بيانات المطوّر (الاسم والإيميل وواتساب) موجودة في الثابت `DEV` داخل `index.html`. عدّلها أو امسحها لو مش عايزها تبقى عامة.
- التطبيق بيستخدم خط **PingAR** لو لقيته في `fonts/PingAR-Medium.ttf`. لو الملف مش موجود هيشتغل بخط النظام من غير مشاكل (هيظهر 404 للخط في الـ console وده طبيعي). لو معاك الخط، حطه في فولدر `fonts/` جنب `index.html`.
